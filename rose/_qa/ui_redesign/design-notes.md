# RoseChart Studio · UI 优化设计说明

## 任务与用户
- 产品：Windows 桌面图表工具「玫瑰图工坊 · RoseChart Studio」（Tkinter 实现，便携运行时）。
- 用户：项目管理人员 / 汇报人，打开 Excel → 检查玫瑰图 → 调配色、拖标签 → 导出图片放进 PPT。
- 首屏主角：中间的图表预览。主动作：导出。数据、配色、样式都是为这张图服务的次级动作。
- 这次任务：文档型 UI 优化，保持功能、品牌图标与现有三栏骨架，重新决定偶然而成的视觉默认值。

## 品类与标杆
- 品类：B 端数据工作台 / 图表编辑台（桌面工具）。
- 同类最好产品的做法：画布占最大面积，工具栏与检查器退到中性表面；面板靠留白与对齐分组，不靠一层层卡片；控件语法统一、状态（hover / pressed / disabled / selected）一眼可辨；辅助文字保持在可读尺寸，不靠 9–12px 灰字营造精致。
- 现状与差距：三栏骨架没问题，但面板被拆成大量带边框的小卡片，「卡片套卡片 + 每条边都画线」让画面发碎；辅助字号普遍 8.5–9.5pt（约 11–12.7px）；控件存在按钮、分段、下划线 Tab、Emoji 提示四种语法；表格有选中态却点了没反应（假交互）。

## 设计北极星
**安静的数据工作台**：图表是唯一主角，界面像一台校准过的仪器——克制的青灰、精准的发丝线、清楚的层级；颜色和注意力都留给图表本身。

- 表面：应用底色 #F2F5F9；内容面板为整片白色表面 + 1px 发丝线；面板内用留白和 11pt 小节标题分组，不叠卡片。
- 色彩：保留品牌青 #0F766E、图表原配色与我的图标资产；中性色偏冷灰，选中等对比的 #5C6B7F 作为辅助文字，不再用低对比浅灰承载信息。
- 字体：界面正文 10.5pt、辅助 10pt、小节标题 11.5pt、品牌标题 14pt；中文优先微软雅黑 UI。
- 控件：统一为圆角（7px）按钮 + 白底软中性分段 + 下划线 Tab；撤销/重做改画线图标；所有可交互元素具备 hover / pressed / disabled 反馈。
- 减法：删除卡片 header 右侧的无信息 hint、提示条 Emoji、重复的推荐说明；空状态给出明确行动入口。

## 现状规范盘点（改造前）
- 颜色：BG #EEF2F6 / PANEL #FFFFFF / BORDER #E2E8F0 / TEXT #0F172A / TEXT_MUTED #64748B / TEXT_FAINT #94A3B8 / PRIMARY #0F766E / PRIMARY_SOFT #E7F4F1 / PREVIEW_BG #E9EEF4。
- 字体：Microsoft YaHei UI；8.5 / 9 / 9.5 / 10 / 10.5 / 11 / 13.5 / 21pt 混用。
- 间距：4 / 5 / 6 / 7 / 8 / 10 / 12 / 14 / 16 / 18 / 22 混用，无统一节奏。
- 派生色：状态成功点 `#16A34A`（SUCCESS token）、透明棋盘 `#FFFFFF/#F7F9FC`、色板卡选中底 `#F4F9F8`、推荐标签底 `PRIMARY_SOFT`；均已在实现中收敛为 token 或派生值。
- 组件：Card（带边框白卡）、FlatButton（矩形）、SegmentedControl、Tabs、ScrollFrame、Slider、CheckRow、ColorButton、PaletteCard、DataTable、StatusBar、Tooltip、BrandMark。
- 表面层级：app bg → card（白 + 边框）→ 卡片内再放次级控件，层级靠边框重复表达。

## 本次改动清单
1. **表面系统**：左右栏改为整片 Inspector 面板（白底 + 发丝边框），面板内分节；删除卡片边框与卡片 header 无信息 hint；统一面板内边距 18px。
2. **字体层级**：建立 10 / 10.5 / 11.5 / 14 四档界面字号，辅助文字不低于 10pt；表格与状态栏同步放大；标题与内容共享同一左锚线。
3. **控件重做**：圆角按钮（primary / secondary / soft / ghost）、图标按钮（画线撤销重做）、软底分段控件、下划线 Tab、精修滑杆/复选框/色板卡；所有状态可见。
4. **主窗口**：左栏合并「数据源 + 统计列」、删除「操作提示」卡；右栏合并标签颜色分组；预览区加发丝边与柔和棋盘格；提示条去 Emoji 去冗余；标题与操作区重排。
5. **空状态**：绘制淡色玫瑰图形 + 一句说明 + 主按钮「打开 Excel」。
6. **修复假交互**：数据概览表点击某一行时，在图表中高亮对应标签并给出状态提示；同时保留表格选中态。
7. 空状态、最小窗口、拖拽中、禁用态、导出的状态一并复核。

## 明确不做
- 不改品牌图标、品牌青、图表配色算法、导出格式与数据逻辑。
- 不加渐变、发光、装饰插画、假数据；不动菜单栏结构。
- 本次是存量界面润色：不加页面级动效，只保留控件 hover / pressed / focus 的即时反馈。
- 未改动的状态沿用改造前截图，并在证据说明里注明。

## 评审与验收结果

### 独立评审（oil-ui「存量已有界面润色评审」，不打分）
已按协议派出独立评审子 Agent 并收到评审报告（未参与制作、未读源码，仅基于截图与规范）。结论：三栏骨架与字号层级成立，不需要重做；剩余问题集中在**图内文字可读性、最小窗口主图尺度、导出页主操作与尺寸主从、原生步进器**。

### 评审反馈与处理
| 评审项 | 处理 |
| --- | --- |
| 问题 1：标签落在深色扇区/浅色棋盘上对比不足，引线发虚 | 自动标签色对比度目标提到 4.0:1；引线加白色底衬；标签落在扇区内时自动加半透明白色圆角底板（拖拽中实时切换），06→见 `05a_dragging_mid.png`。 |
| 问题 2：最小窗口把主图缩成次要尺度、标签不可读 | 最小窗口由 1240×790 提高到 **1440×870**；左右栏宽 322/402 → **314/394**，把宽度让给画布；底色和字体不变。07 已按新最小尺寸重拍。 |
| 问题 3：导出页出现两个同级主操作 | 页头按钮降级为次级「导出设置」，只负责切到导出面板；导出页内只保留一个实心主操作「导出当前图」，其余为次级/文字动作。 |
| 问题 4：尺寸预设与宽高字段同屏两套真值 | 预设为主、宽高为派生：非「自定义」时宽高字段禁用并显示派生值，加一行说明「尺寸由上方预设决定，选择「自定义」后可修改」；切到自定义后才可编辑。 |
| 问题 5：导出数字字段仍是系统原生步进器 | 宽/高/DPI/百分比小数位全部改为与其他字段一致的文本输入（无原生上下箭头），保留范围校验。 |
| 提升 1：表头与数据锚线、百分比精度 | 类别表头左对齐、数量/占比表头右对齐；表格百分比统一为两位小数（与图表一致）。 |
| 提升 2：配色页层级（当前方案、标签配色先可达） | 顺序改为 **当前方案 → 推荐配色 → 标签配色 → 类别颜色 → 全部配色方案**；新增「当前方案」色条行；删除推荐卡上重复的「推荐」胶囊；同一色板同时出现在推荐与全量库时，推荐区保留主选中态，全量库用次级「已选」标签，不双勾。 |
| 提升 3：棋盘纹理退后 | 棋盘第二色由 `#F3F6FA` 降到 `#F7F9FC`，保留透明语义；新增 480px 缩略图检查（先看到环图）。 |
| 空状态残留提示 | 无数据时隐藏底栏的拖拽提示；「自动排列」在无图时禁用；数据概览的「点击行定位标签」仅在确有行时显示。 |
| 文字重复 | 删除状态栏重复的行数（左侧消息保留）、推荐卡重复胶囊；「自动布局/自定义布局」统一为「布局：自动 / 布局：自定义」。 |

### 保留项（评审点名要求不要磨平）
- 左栏统计表把数量与占比严格右对齐的列节奏；
- 品牌青只落在主动作、选中/当前状态和滑杆上的克制用法；
- 整块面板加分节留白，而不是卡片套卡片。
